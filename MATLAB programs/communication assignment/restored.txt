**Write `'d'` next.** Steps:
- Open the file with `'r','ieee-be'`. Error if it's missing.
- Read `originalSize`, `numCodes` (uint32), then the rest as `uint8`.
- If the file is shorter than 8 bytes, error: `'Not a valid mzip file'`.
- `codes = unpack12(packed, numCodes);`
- `data = lzw_decode(codes);`
- If `numel(data) ~= originalSize`, error: `'Corrupt file: size mismatch'`. This is a useful sanity check, and examiners like it.
- Write `data` with `fwrite(fid, data, 'uint8')`.

Watch the empty-file case: `numCodes = 0` means `unpack12` and `lzw_decode` must return empty, and you should still create an empty output file.

**Then `'i'`.** Read only the 8-byte header, and get the compressed size from `dir(infile).bytes`. Print:
- original size
- compressed size (whole file, header included)
- ratio = original / compressed
- bits per input byte = 8 × compressed / original

Guard against `original == 0`, which would divide by zero. Entropy needs the original data, so compute it in `run_tests.m`, not here.
